# Projects

## 1. PNR Monitor

A railway PNR monitoring web application designed to automatically track railway booking status and notify users when the status changes.

### Features

- PNR status monitoring
- Automatic periodic status checking
- WL, RAC and CNF status tracking
- Status change detection
- Monitoring history
- Email notifications
- Multiple PNR monitoring
- Pause / Resume monitoring
- PNR management
- Monitoring status and check history
- Dashboard-based interface

### Technology Stack

- HTML
- CSS
- JavaScript
- Node.js
- Supabase
- Vercel

### Project Concept

The application periodically checks registered PNR numbers through a railway PNR service and compares the latest status with the previously stored status.

When a meaningful status change is detected, the system can notify the user through the configured notification mechanism.

### Live Project

**PNR Monitor:**  
https://pnr-monitor.vercel.app/
